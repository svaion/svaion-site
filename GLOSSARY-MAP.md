# Glossary Map

## Contexts

- [Company](./src/contexts/company/GLOSSARY.md): who Svaion is, how it may be named, and how it can be reached
- [Offering](./src/contexts/offering/GLOSSARY.md): what Svaion builds, for whom, and how soon a first release lands
- [Delivery](./src/contexts/delivery/GLOSSARY.md): how an engagement runs and who answers for AI-assisted work
- [Showcase](./src/contexts/showcase/GLOSSARY.md): fictional scenarios that show AI-assisted, human-led work end to end

## Relationships

- **Company → every context**: Company owns the names, the tagline, the approved messages and the contact channels; the others quote them, never restate them
- **Offering → Delivery**: Delivery's Launch stage delivers the Focused MVP inside Offering's MVP window
- **Delivery → Showcase**: every Scenario follows Delivery's rule that AI-assisted work has an accountable person; a Scenario's sign-off is that person acting
- **Homepage**: not a context; a read model that composes all four into one page
